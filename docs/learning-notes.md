# Cybersecurity Learning Notes

## Password Security

Strong passwords are typically longer and use a mixture of character types. Passwords should be unique for different accounts, and multi-factor authentication adds another layer of protection.

## File Hashing

A cryptographic hash creates a fixed-length representation of data. SHA-256 is commonly used to verify whether a file has changed.

## TCP Ports

A TCP port identifies a network service endpoint. A basic connect scan attempts a normal TCP connection to selected ports and reports whether the connection succeeds.

## URL Structure

A URL can contain a scheme, hostname, port, path, query string, and fragment. Understanding these components is useful when studying web technologies and security.

## Ethical Security Testing

Security tools should be used only against systems and data for which you have authorization. Learning in a local lab or controlled environment is the safest way to practice.
