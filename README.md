# 🔐 Cybersecurity Toolkit

A beginner-friendly collection of **Python cybersecurity utilities** created for learning, experimentation, and authorized security testing.

> ⚠️ **Ethical Use:** Use these tools only on systems, files, networks, and domains that you own or have explicit permission to test.

## 🎯 Purpose

This project is part of my cybersecurity learning journey. It focuses on practical security concepts while improving Python, networking, Linux, and problem-solving skills.

## 🧰 Tools

| Tool | Purpose |
|---|---|
| 🔑 Password Strength Checker | Evaluates basic password-strength characteristics |
| #️⃣ File Hash Generator | Generates SHA-256 hashes for file integrity checks |
| 🌐 Local Port Scanner | Checks selected TCP ports on an authorized host |
| 🔗 URL Analyzer | Displays basic URL components |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/s21154308-max/cybersecurity-toolkit.git
cd cybersecurity-toolkit
```

### 2. Check Python

```bash
python --version
```

Python 3.10+ is recommended.

### 3. Run a tool

```bash
python tools/password_checker.py
```
